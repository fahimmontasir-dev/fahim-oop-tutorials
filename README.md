## How to Run the Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/fahimmontasir-dev/fahim-oop-tutorials.git
   ```

2. Open the desired tutorial folder.

3. Compile the Java files:

   ```bash
   javac *.java
   ```

4. Run the main class:

   ```bash
   java Main
   ```

   For Tutorial 7, run:

   ```bash
   java QuizBattleGUI
   ```

   Tutorial 7 requires a graphical environment to display its Swing window.
